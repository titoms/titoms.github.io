THE PROBLEM

Subtitling eats a creator's day, and the tools force a bad trade-off.

Independent video creators spend hours transcribing and timing captions by hand. The faster web tools fix this — but only by uploading raw, unreleased footage to someone else's servers, which is slow, expensive at scale, and a real privacy problem.

  • Manual timing is brutal. A 20-minute video can take 2–3 hours to caption cleanly.
  • Cloud tools leak your work. Unreleased footage has to be uploaded before you can even start.
  • Subscriptions stack up. Per-minute pricing punishes exactly the people who publish the most.

Who it's for

solo creators · editors · studios

YouTubers, course creators and small post-production teams who publish often, care about privacy, and want captions done in minutes — on their own machine.

THE SOLUTION

One desktop app that runs the whole caption workflow locally.

Keevo wraps an on-device speech model in a focused editor. Drop in a video, get an accurate transcript in minutes, refine it in a timeline built for captions, and export broadcast-ready subtitle files — all offline.

TECHNICAL CHALLENGE

Running a heavy AI model on a creator's laptop — smoothly.

The hard part wasn't the UI; it was making on-device inference feel instant without freezing the interface or melting the GPU on long files.

What made it hard

  • Off-main-thread inference. Model runs in a worker process so the editor never blocks.
  • Streaming results. Transcript segments stream into the UI as they finish, not at the end.
  • Native packaging. Shipping GPU binaries across macOS and Windows from one codebase.
