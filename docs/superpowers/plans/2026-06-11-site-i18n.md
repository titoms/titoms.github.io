# Site I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add static English, French, and Spanish localization with browser-language detection and manual selectors.

**Architecture:** Add a small i18n helper and localized content dictionaries, then route existing pages through locale-aware variants. Keep Cloudflare Pages static output and avoid runtime translation services.

**Tech Stack:** Astro 6, React 18 islands, TypeScript, MDX content collections, Tailwind CSS.

---
